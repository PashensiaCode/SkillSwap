# SkillSwap

SkillSwap is a platform for exchanging skills between users — "I can teach" / "I want to learn".

## 🛠️ Technologies

- React
- TypeScript
- Vite
- Redux Toolkit
- React Redux
- React Router
- React Hook Form
- Yup
- SCSS / CSS
- ESLint
- Prettier
- Stylelint
- Storybook
- Jest
- Vitest

## 🚀 Installation and Setup **Local** 1. Clone the repository: 
git clone https://github.com/PashensiaCode/SkillSwap.git
2. Navigate to the project directory and switch to the branch develop:
cd SkillSwap_45_2
git checkout develop
3. Install the dependencies:
npm i
4. Start the application:
npm run dev
The application will be available at http://localhost:5173
