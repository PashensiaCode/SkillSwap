🌿 Git Workflow
**Switch to the develop branch:**
git checkout develop
git pull  # Pull the latest changes from develop before starting each task
**Create a new branch for the task:**

**Branch naming format:**

<type>/<short-task-description>

**Available branch types:**

feature/ — a new feature or component
fix/ — a bug fix
refactor/ — code improvements without changing functionality
docs/ — documentation changes
chore/ — maintenance updates (dependencies, configuration, etc.)

**Example:**

git checkout -b feature/add-footer
Make commits throughout the development process:
git add <file-name-or-.>
git commit -m "feat: add example component"

Commit messages follow the Conventional Commits specification.

**Push the branch:**
git push -u origin feature/add-footer
Open a Pull Request on GitHub:

**Create a Pull Request from:**

feature/... → develop

🚀 Installation & Setup
Local Development
**Clone the repository:**
git clone https://github.com/PM-YandexPracticum/SkillSwap_45_2.git
**Navigate to the project directory and switch to the develop branch:**
cd SkillSwap_45_2
git checkout develop
**Install dependencies:**
npm install
**Start the development server:**
npm run dev

**The application will be available at:**

http://localhost:5173
